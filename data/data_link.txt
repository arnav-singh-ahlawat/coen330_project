Dataset: MetroPT-3 Dataset
Source: UCI Machine Learning Repository
Download page: https://archive.ics.uci.edu/dataset/791/metropt+3+dataset

The raw dataset files are not committed to GitHub because they are large.

To reproduce the project:
1. Download the MetroPT-3 dataset from UCI.
2. Extract the archive locally if needed.
3. Place the raw CSV file inside:

data/raw/

Do not commit raw dataset files, ZIP files, virtual environments, or large model files.
